# ECAssistant

**Local-first AI agent platform** — namespace root package.

This package reserves the `ECAssistant` ID. You probably want one of these instead:

- **[ECAssistant.Core](https://www.nuget.org/packages/ECAssistant.Core)** — the agent engine: tools, sessions, memory
- **[ECAssistant.TUI](https://www.nuget.org/packages/ECAssistant.TUI)** — terminal UI library
- **[ECAssistant.LLM.Server](https://www.nuget.org/packages/ECAssistant.LLM.Server)** — OpenAI-compatible local LLM server
